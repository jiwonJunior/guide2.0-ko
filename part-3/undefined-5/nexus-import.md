#### 1. Component Agent Url {#1-component-agent-url}

Use NEXUS Import에서 NEXUS Import 기능 사용 여부를 설정합니다. 활성화 시 Project 메뉴 하단에 NEXUS Import 메뉴 추가됩니다.
