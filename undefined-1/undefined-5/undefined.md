# 서버, 서비스 연동 설정

#### 1. 메일 서버 설정

시스템에서 발송하는 알림 메일(CVE 알림, 워크플로우 메일 등)을 보낼  메일 서버를 설정합니다. 시스템이 메일 전송을 정상적으로 수행할 수 있도록 SMTP 서버 정보를 설정할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>

#### 2.  FossID 서버 설정

ClaritySC에서 FossID 서버를 연동할 때 필요한 접속 정보를 설정할 수 있습니다. 서버 설정이 완료되어야지 FossID 서버에 API 요청을 보내고 검증 결과를 조회할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>



#### 3. Clarity 서버 설정

* ClaritySC에서 Clarity 서버를 연동할 때 필요한 접속 정보를 설정할 수 있습니다. 서버 설정이 완료되어야지 Clarity 서버에 API 요청을 보내고 검증 결과를 조회할 수 있습니다.
* **Skip Clarity Workflow** 항목을 통해서 워크플로우 과정을 건너 뛸 수 있도록 설정할 수 있습니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (103).png" alt=""><figcaption></figcaption></figure></div>



#### 4. ClarityAIR 서버 설정

* ClaritySC에서 ClarityAIR 서버를 연동할 때 필요한 접속 정보를 설정할 수 있습니다. 서버 설정이 완료되어야지 ClarityAIR 서버에 API 요청을 보내고 검증 결과를 조회할 수 있습니다.
