#### 1. 스캔  도구 설정

**Usage Verif. Tools** 메뉴에서 스캔 도구의 사용 여부를 설정할 수 있습니다. 선택된 도구만 표시됩니다. **Clarity** 도구는 기본으로 활성화되어 있습니다.

#### 2. HTTP Client Timeout 설정

**HTTP Client Timeout (seconds)**&#xC5D0;서 클라이언트가 요청 후, 응답을 기다리는 최대 시간을 설정합니다.\
지정된 시간을 초과하면 연결이 자동으로 종료됩니다.

#### 3. 기본 언어/지역 설정

**Default Locale**에서 시스템 기본 언어를지정합니다.

#### 4. CVE 동기화(크롤링) 설정

**CVE Crawling Time**에서CVE 크롤링 실행할 시간을(HH:mm)을 설정합니다. 설정에 시간에 하루 한번 실행됩니다.

#### 5. 프로젝트 완료 예정일 설정

**Default Completion Request Offset**에서 프로젝트의 완료 예정일 기본 값 설정합니다.

#### 6. 검증 타임아웃 설정

**Verification Timeout**에서검증 도구를 통해 파일 검증을 수행할 때, API 요청 전송 후 응답 시간까지(Timeout)을 설정합니다.&#x20;

#### 7. 사전검토 기능사용여부

**Use Preview**에서 사전검토 기능 사용 여부를 설정합니다. 활성화 시 Project 메뉴 하단에 **Previews List** 메뉴 추가됩니다.

#### 8. VEX 기능 사용여부

**Use VEX**에서 VEX 기능의 사용 여부를 설정합니다. 활성화 시 VEX 정보가 표시됩니다.
