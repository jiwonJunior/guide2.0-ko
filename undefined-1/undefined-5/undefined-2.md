# 도구, 언어 및 기타 설정



### 시스템 도구 및 기타 설정

<figure><img src="../../.gitbook/assets/image (234).png" alt=""><figcaption></figcaption></figure>

#### 1. 스캔  도구 설정

Usage Verif. Tools 메뉴에서 스캔 도구의 사용 여부를 설정할 수 있습니다. 선택된 도구만 표시됩니다. **Clarity** 도구는 기본으로 활성화되어 있습니다.

#### 2. HTTP Client Timeout 설정

HTTP Client Timeout (seconds)에서 클라이언트가 요청 후, 응답을 기다리는 최대 시간을 설정합니다.\
지정된 시간을 초과하면 연결이 자동으로 종료됩니다.

#### 3. 기본 언어/지역 설정

Default Locale에서 시스템 전반에서 사용할 기본 언어 및 지역을 지정합니다.

#### 4. CVE 동기화(크롤링) 설정

CVE Crawling Time에서CVE 크롤링 실행할 시간을(HH:mm)을 설정합니다. 설정에 시간에 하루 한번 실행됩니다.

#### 5. 프로젝트 완료 예정일 설정

Default Completion Request Offset에서 프로젝트의 완료 예정일 기본 값 설정합니다.

#### 6. 검증 타임아웃 설정

Verification Timeout에서검증 도구를 통해 파일 검증을 수행할 때, API 요청 전송 후 응답 시간까지(Timeout)을 설정합니다.&#x20;

#### 7. 사전검토 사용여부

Use Preview에서 사전검토 기능 사용 여부를 설정합니다. 활성화 시 Project 메뉴 하단에 **Previews List** 메뉴 추가됩니다.

#### 8. 컴포넌트, 라이선스 정보 동기화

Gensis Sync에서 \[Sync]버튼을 누르면 컴포넌트, 라이선스 정보를 동기화합니다. Open Source 메뉴에서 동기화된 데이터 확인할 수 있습니다.

* **지금 동기화(Sync)**: 마지막으로 완료된 지점부터 동기화를 계속 진행합니다.
* **전체 동기화(Full Sync)**: 동기화 처음부터 다시 시작하여 모든 컴포넌트 라이선스를 다시 가져옵니다.
