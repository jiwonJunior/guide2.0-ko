# FossID Import 설정

#### FossID Import 기능

System > Preferences > FOSSID IMPORT SETTINGS 에서 기 스캔된 FOSSID 프로젝트를 가져오고, 자동으로 생성될 프로젝트 기본 값을 설정합니다.

<figure><img src="../../.gitbook/assets/image (127).png" alt=""><figcaption></figcaption></figure>



1. **Asset Classification**

* FossID Import 시, 자동 생성되는 프로젝트의 자산중요도 기본 값을 지정합니다.



2.  **License Policy**

    * FossID Import 시, 자동 생성될 프로젝트의 라이선스 정책을 설정합니다.


3. **Distribution Scope**

* FossID Import 시, 자동 생성될 프로젝트의 포 범위(Internal / External / SaaS )를 설정합니다.



4. **License**

* FossID Import 시, 자동 생성될 프로젝트의 대표 라이선스(Commercial / Open Source 등)를 설정합니다.



5. **Import Projects**&#x20;

* \[Import] 버튼을 클릭하면 FossID 프로젝트를 가져오기 위한 세부 설정 팝업 창이 표시됩니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (129).png" alt="" width="437"><figcaption></figcaption></figure></div>

&#x20; **a. Ignore Existing Project**

* 중복 프로젝트 Import 여부를 설정합니다. 이미 시스템에 동일한 프로젝트가 존재 할 경우,&#x20;

&#x20; **b. All FossID Projects**

* 모든 프로젝트를 가지고 옵니다. (시간이 오래 소요될 수 있습니다.)

&#x20; **c. Date Range**

* 최근 일주일 또는 날짜를 지정하여 해당하는 기간의 모든 프로젝트를가져옵니다.

&#x20; **d. FossID 프로젝트 코드**

* FossID의 **Project Code**를 입력하여 프로젝트를 가져옵니다. 쉼표(,)로 구분하여 여러 개의 프로젝트를 가지고 올 수 있습니다.



6. **Import History**

* 가져 온 FossID 프로젝트를 목록을 확인할 수 있습니다.
