# NOTICE HEADER 설정

#### 1. 고지문 HEADER 설정

* System > Preferences > NOTICE HEADER에서는 출력될 고지문의 HEADER 기본 값을 설정할 수 있습니다.
* 고지문(Notice) 생성 시 기본 값으로  입력될 고지문 헤더(Notice Header)를 설정할 수 있습니다. 고지문을 작성할 때마다 상단에 반복적으로 들어가는 고정 문구(저작권 문구 등)를 관리자가 미리 등록해두면, 해당 내용을 기본 값으로 자동 채워집니다.
