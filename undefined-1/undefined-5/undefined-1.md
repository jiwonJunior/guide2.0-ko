# 식별 규칙 설정

#### 식별 규칙 설정

**System > Preferences > ID Format Settings에서** 프로젝트, 검증보고서, 고지 정보의 고유 ID를 생성할 때, 사용되는 규칙(접두어 + 일련번호 자릿수)을 설정하는 메뉴입니다. 이 설정에 따라 시스템이 자동 생성하는 ID의 표기 방식이 결정됩니다.
