# 고지문 작성하기

#### 1. 고지문 워크플로우 단계 별 설명

**Step 1 - Write 1/2**

\[Write Notice Information] 버튼을 눌러서 고지문을 작성합니다.

<figure><img src="../../.gitbook/assets/image (136).png" alt=""><figcaption></figcaption></figure>



**Step 1.1 - Notice Header 작성**

먼저 Notice Header를 작성합니다. 해당 내용은 고지문 상단에 표시되는 헤더이며, [환경설정](../undefined-5/notice-header.md)에서 기본 값을 설정할 수 있습니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (200).png" alt="" width="506"><figcaption></figcaption></figure></div>



**Step 1.2 - Notice 항목 작성**

* 컴포넌트를 클릭하면 고지문에 포함될 URL, Copyright, License Text를 작성할 수 있습니다.
* DB에 기존 데이터가 있는 경우 해당 값이 기본 값으로 자동 표시됩니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (137).png" alt="" width="563"><figcaption></figcaption></figure></div>



* Select 항목을 선택하면 이전에 작성한 목록 중에서 선택할 수 있습니다.
* Custom을 클릭하면 새로 작성할 수 있습니다.
* 하단의 Next 클릭해서 다음 컴포넌트로 이동할 수 있습니다.

<div align="left"><figure><img src="../../.gitbook/assets/image (139).png" alt="" width="563"><figcaption></figcaption></figure></div>



**Step 2 - Review**

고지문 작성 완료 후, 검토 요청합니다. \[Confirm Notice] 버튼 클릭해서 고지문 작성 완료합니다.

<figure><img src="../../.gitbook/assets/image (104).png" alt=""><figcaption></figcaption></figure>



**Step 3 - Notice(고지문 다운로드)**

고지문 작성이 완료된 상태로 \[Download] 버튼을 클릭하면, 고지문을 Text 또는 HTML 형식으로 다운로드할 수 있습니다.

<figure><img src="../../.gitbook/assets/image (141).png" alt=""><figcaption></figcaption></figure>
