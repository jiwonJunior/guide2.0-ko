# 알림 기능

#### 1.  메일 서버 설정 (필수 선행 작업)

메일 알림 기능을 사용하기 위해서는 환경설정 메뉴에서 [메일 서버 설](undefined-5/undefined.md)정이 완료되어야 합니다.



#### 2. 메일 알림 수신 여부 설정

우측에 사용자 정보를 클릭해서 \[Profile Settings] 클릭해서

<figure><img src="../.gitbook/assets/image (99).png" alt=""><figcaption></figcaption></figure>



Mail Reception에서 메일 알림 수신 여부 설정할 수 있습니다.

<div align="left"><figure><img src="../.gitbook/assets/image (100).png" alt="" width="533"><figcaption></figcaption></figure></div>



<mark style="background-color:yellow;">위 두 가지 설정이 모두 완료되면 다음과 같은 메일 알림이 발송됩니다.</mark>



**CVE 알림**

* 프로젝트에 새로운 CVE가 포함되면, 해당 프로젝트의 생성자와 멤버에게 알림 메일이 발송됩니다.
* 영문으로 발송됩니다.

<div align="left"><figure><img src="../.gitbook/assets/image (98).png" alt="" width="411"><figcaption></figcaption></figure></div>



**프로젝트 검증 워크플로우 알림**

* 검증 워크플로우가 각 단계로 진행될 때마다 프로젝트 생성자와 멤버에게 메일 알림이 발송됩니다.
* 메일은 사용자가 선택한 언어로 발송됩니다.

<div align="left"><figure><img src="../.gitbook/assets/image (97).png" alt="" width="458"><figcaption></figcaption></figure></div>
