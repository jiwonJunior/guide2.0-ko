# ClaritySC란

#### ClaritySC란?

ClaritySC(Clarity Supply Chain)는 기업들이 오픈소스 사용으로 발생할 수 있는 리스크를 사전에 관리하기 위한 **오픈소스 관리 시스템**입니다. 기업은 ClaritySC의 **관리 포탈(CSC)**&#xC744; 통해 오픈소스 검증을 수행함으로써, 개발 및 배포 이후 발생할 수 있는 문제를 사전에 예방할 수 있습니다. 또한, 다양한 SBOM 관리 기능 지원하여 확장 가능한 **SBOM 관리 통합 플랫폼**입니다.

#### **CSC 왜 필요할까?**

1. 현재 S/W 개발 환경에서는 오픈소스 사용이 필수지만, 동시에 아래와 같은 _**리스크**_&#xAC00; 생깁니다.
   1. 라이선스 정책 위반 가능성
   2. 오픈소스에서 취약점(CVE) 발견
2. 검증 시, 얼마나 정확하게 _라이선&#xC2A4;_&#xC640; 취약점(CVE)이 검출되는 지 중요 → Clairty, FossID 검증 도구를 사용해서 신뢰성 있는 검증 결과를 제공
3. 검증 후, 검증보고서(SBOM), 고지문을 생성해서 필요한 곳에 제출 가능
4. 기업에서 관리가 어려운 SBOM을 다양한 SBOM 기능을 제공



***

#### **CSC 강점 3가지**

1. 회사 _**정책**_&#xC5D0; 따른 _**라이선스 정책**_ 설정 가능
2. 회사의 _**자산 중요도**_&#xC5D0; 따른 _**보안취약점**_ 설정 가능
3. 다양한 SBOM 관리 기능 제공
   1. SBOM Import, SBOM 머지, SBOM비교 기능
