# 검증 하기

#### 1. 검증 기능 개요

* ClaritySC는 Clarity, FossID, ClarityAIR 검증 도구와 SBOM Import 기능을 지원합니다.
* 프로젝트에서  Clarity, FossID, ClarityAIR 검증 도구와 SBOM Import를 선택하여 파일 분석을 요청하고, 검증 워크플로우를 통해 결과를 관리할 수 있습니다. 또한 검증 결과를 기반으로 SBOM을 생성할 수 있습니다.

#### 2. 검증 워크플로우 설명

* Clarity, FossID, ClarityAIR, SBOM Import 각각 고유한 검증 워크플로우 단계를 가지고 있습니다.
* Clarity의 경우, 워크플로우를 중간 단계 없이 바로 Ready 단계로 이동 시켜 검증을 완료할 수 있습니다.
  * 해당 기능은 환경설정 메뉴(System > Preferences > Server Settings > Clarity Server)에서\
    **Skip Clarity Workflow** 옵션을 체크하여 설정할 수 있습니다. ([Clairty 워크플로우 설정 방법](../../undefined-1/undefined-5/undefined.md))
