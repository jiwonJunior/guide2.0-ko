# 프로젝트 생성하기



※ **Role**에서 **Manager, Product Manager** 권한 없다면 새 프로젝트 생성할 수 없습니다. 상세한 권한 부여는 [\[Role 설정 방법\]](../undefined-1/role.md) 항목을 참고해 주세요.



#### 새 프로젝트 생성

* 새 프로젝트 생성 방법으로 2가지가 있습니다.



#### 1. Project 메뉴에서 생성하기

* Project > Project List 메뉴에서 \[Add new project] 버튼을 클릭해서 새 프로젝트 생성합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (42).png" alt="" width="563"><figcaption></figcaption></figure></div>





**1.1. 새 프로젝트 정보 입력**

* Add New Project에서 빨간색으로 표시된 필수 값 입력하고 이 프로젝트의 **Project Manager** 설정할 수 있습니다.&#x20;
* 프로젝트의 Asset Classification, Distribution, License Policy, 대표 License선택합니다. 미 선택 시 디폴트 값 선택됩니다. &#x20;
* \[Save] 버튼 클릭해서 신규 프로젝트 생성합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (232).png" alt="" width="563"><figcaption></figcaption></figure></div>

* **Project Name**: 신규로 등록할 프로젝트 이름을 입력합니다.
* **Project Manager**: 프로젝트 관리자를 지정합니다. (Project Manager 권한이 있는 계정만 표시)
* **Product Name**: 이 프로젝트의 프로덕트를 선택합니다.
* **Completion Request Date**: 프로젝트의  완료 예정일을 입력합니다. ([환경설정에서 기본 값 설정 가능](../undefined-1/undefined-5/undefined-2.md#id-8)).
* **Asset Classification**: 프로젝트의 자산 중요도를 설정합니다.
* **Distribution**: 프로젝트가 내부, 외부 또는 SaaS 형태로 제공되는지 지정합니다. 기본 값은 SaaS입니다.
* **License Policy**: 프로젝트에 적용할 라이선스 정책을 선택합니다.
* **License**: 프로젝트의 대표 라이선스를 지정합니다. 기본 값은 Commercial License이며, 프로젝트를 오픈소스로 공개하는 경우에만 오픈소스 라이선스를 선택합니다.
* **Preview List**: 클릭 시, _Select Preview_ 팝업이 열리며, 원하는 Preview 항목을 선택할 수 있습니다.
* **Remark**: 프로젝트에 대한 비고 사항을 작성할 수 있습니다.
* **Document**: 프로젝트와 관련된 추가 문서나 파일을 첨부할 수 있습니다.



***



**1.2. 프로젝트 상세**

* Project Details에서는 프로젝트 정보와 사전 검토된 컴포넌트 목록을 확인할 수 있으며, 선택한 검증 도구로 검증을 진행할 수 있습니다.

<div align="left"><figure><img src="../.gitbook/assets/image (233).png" alt="" width="563"><figcaption></figcaption></figure></div>



**1.3. 사전검토**

* \[Select Preview]을 클릭해서 사전검토 항목을 선택하면 사전 검토된 컴포넌트 목록을 표시합니다.

<div align="left"><figure><img src="../.gitbook/assets/image (46).png" alt="" width="563"><figcaption></figcaption></figure></div>



**1.4. 검증하기**

* \[Add Verification Request] 버튼을 클릭하면, 선택한 스캔 도구를 통해 파일 분석이 시작되며 이후, 자동으로 검증 프로세스가 진행됩니다.

<div align="left"><figure><img src="../.gitbook/assets/image (23).png" alt="" width="563"><figcaption></figcaption></figure></div>



***

#### 2. Product Management 메뉴에서 생성하기

* 새로운 프로젝트를 생성하는 두 번째 방법으로, 프로덕트 관리 메뉴 내에서 프로젝트를 추가할 수 있습니다. 상세한 신규 등록 절차는 [\[프로덕트에서 프로젝트 생성하기\]](../undefined-1/undefined-2.md#id-3.-product-manager) 내용을 참고해 주세요.
