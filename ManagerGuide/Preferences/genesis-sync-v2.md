# GENESIS SYNC 동기화



#### Genesis Sync  동기화 가이드

1. Genesis 내부 DB 데이터는 하루 한 번 자동으로 동기화됩니다. 최신 데이터를 즉시 반영하거나 상태 점검이 필요한 경우 각 모듈별로 수동 동기화를 진행할 수 있습니다
2. Gensis Sync에서 \[Sync]버튼을 누르면 컴포넌트, 라이선스 정보를 동기화합니다. **Open Source 메뉴**에서 동기화된 데이터 확인할 수 있습니다.

* **지금 동기화(Sync)**: 마지막으로 완료된 지점부터 동기화를 계속 진행합니다.
* **전체 동기화(Full Sync)**: 동기화 처음부터 다시 시작하여 모든 컴포넌트 라이선스를 다시 가져옵니다.

<mark style="background-color:$primary;">※최초 설치 시 Genesis Sync v2 선택 후, 전체동기화 필요합니다.</mark>
